# Калькулятор сетки MEXC

Локальный калькулятор LONG-сетки для бессрочных фьючерсов MEXC. Он показывает четыре уровня входа с маржой 1, 2, 3 и 4 USDT и ликвидацию после каждого шага. Ордеры не отправляются.

## Запуск в Windows

Откройте командную строку в папке проекта и выполните одну команду:

```bat
start.bat
```

Сценарий создаст `.venv`, установит зависимости из `requirements.txt` при первом запуске, запустит приложение и откроет браузер на `http://127.0.0.1:5000`. Для остановки нажмите `Ctrl+C`.

## Расчёт

- Цена первого входа автоматически берётся из публичного API MEXC для выбранной пары; её можно заменить вручную.
- По умолчанию задаётся целое плечо. Можно переключиться на подбор плеча по целевой ликвидации после четвёртого шага.
- MMR равен нулю, если его не ввели. Для калибровки можно указать фактическую ликвидацию первого шага вместе с плечом.
- Ставку и количество списаний фандинга можно задать отдельно. Комиссия не включена в формулы сетки.
- Расчёт использует маржу × плечо / цена и коэффициент следующего входа 0.85.

MEXC используется для списка фьючерсных пар и текущих цен. Приложение не торгует и не запрашивает API-ключи.
