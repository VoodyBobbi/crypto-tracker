# LONG-сетка MEXC Futures

Локальное приложение для расчёта и запуска четырёх LONG-ордеров.

## Запуск

1. Создайте API-ключ MEXC с правами **View Account Details**, **View Order Details** и **Order Placing**. Вывод средств не включайте. Доступ зависит от KYC, региона и допуска аккаунта; проверьте, что правила MEXC разрешают автоматизированную торговлю.
2. Скопируйте `.env.example` в `.env` и заполните `MEXC_API_KEY` и `MEXC_API_SECRET`.
3. Запустите `start.bat`.

Ключ хранится локально в `.env`; файл исключён из Git.

## Сетка

Кнопка запускает вход LONG до **10 USDT общего бюджета**: первый шаг — маржа до 1 USDT, затем три лимитных шага, рассчитанных от фактического исполнения первого. Объёмы округляются вниз по правилам контракта. В бюджет входят комиссия и стресс-резерв неблагоприятного фандинга до шага 4 (с запасом на одно дополнительное списание); размеры шагов 2–4 подстраиваются под остаток. Для комиссии берётся максимум из данных аккаунта и опубликованной MEXC API-ставки: [текущая таблица](https://www.mexc.com/announcements/article/updates-to-api-futures-trading-fees-jun-1-2026-17827791535742). Изолированная маржа обязательна, свободного баланса должно быть не менее 10 USDT.

Первый вход отправляется как исполняемый IOC-ордер с ценовым пределом около лучшего ask. Если он не исполнится полностью, остальные шаги не ставятся. При сбое постановки лимиток приложение отменяет уже отправленные им лимитные ордера, когда это возможно; первый вход остаётся открытым.

Расчёт использует данные MEXC: контракт, цену, комиссию, funding, плечо и параметры риска. Резерв funding рассчитан только до указанного срока шага 4. Из-за минимального объёма контракта бюджет может быть использован не полностью. Изменение цены, комиссии, funding, проскальзывание или гэп могут привести к ликвидации; расчёт не даёт гарантии её предотвращения.
