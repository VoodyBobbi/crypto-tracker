# Калькулятор LONG-сетки MEXC

Локальная оценка четырёх входов с маржой 1, 2, 3 и 4 USDT. Ордера не выставляет.

## Запуск

1. Создайте API-ключ MEXC только для чтения с правами **View Account Details** и **View Order Details**. Торговля и вывод средств не нужны.
2. Скопируйте `.env.example` в `.env` и заполните `MEXC_API_KEY` и `MEXC_API_SECRET`.
3. Запустите `start.bat`.

Ключ хранится локально в `.env`; файл исключён из Git.

## Что учитывается

Котировки и фандинг берутся из MEXC. Расчёт также читает параметры контракта и риск-тиры, комиссии (берёт наибольшую найденную), ликвидационную комиссию, баланс, плечо, открытые позиции и активные заявки. Для фандинга берётся максимальная текущая неблагоприятная ставка; весь рассчитанный объём считается открытым весь указанный горизонт. Если активная заявка может увеличить риск до шага 4, расчёт останавливается. Кросс-маржа с залогом не только в USDT не поддерживается.

Суммы шагов и коэффициент сетки фиксированы: следующий вход ставится на 85% расстояния от средней цены до расчётной ликвидации предыдущего шага. Первая цена по умолчанию — fair price MEXC, её можно изменить. Горизонт фандинга до шага 4 задаётся вручную в часах.

## Ограничение

Калькулятор проверяет, что каждый следующий вход в модели выше ликвидации предыдущего шага. Автодобавление маржи и проскальзывание не моделируются. Цена, фандинг, комиссии и правила риска могут измениться, а резкий гэп — перескочить уровень входа; гарантии от реальной ликвидации нет.
