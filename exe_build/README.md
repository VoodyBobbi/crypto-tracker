# 📦 EXE Приложение - Калькулятор Сетки MEXC

Это папка для сборки исполняемого файла (.exe) приложения.

## 🚀 Быстрый старт

### 1. Установка зависимостей (один раз)

```bash
# Установите PyInstaller и остальные зависимости
pip install PyInstaller
pip install -r ../requirements.txt
```

### 2. Сборка EXE

```bash
# Перейдите в эту папку
cd exe_build

# Запустите скрипт сборки
python build_exe.py
```

Процесс займет несколько минут. После завершения:
- Готовый EXE файл будет в папке `release/`
- Вы сможете скопировать `КалькуляторСетки.exe` куда угодно и запустить на любом Windows компьютере

### 3. Запуск готового приложения

Просто двойной щелчок по `КалькуляторСетки.exe`!

## 📂 Структура папок

```
exe_build/
├── app.spec              # Конфигурация PyInstaller
├── build_exe.py          # Скрипт сборки
├── build/                # Временные файлы сборки (удаляются автоматически)
├── dist/                 # Интермедиальные файлы
└── release/              # 📌 ГОТОВЫЙ EXE ФАЙЛ НАХОДИТСЯ ЗДЕСЬ
    └── КалькуляторСетки.exe
```

## 🔧 Персонализация (опционально)

### Изменить иконку приложения

1. Создайте или подготовьте иконку в формате `.ico` (256x256 или больше)
2. Сохраните её как `app_icon.ico` в этой папке
3. Отредактируйте `app.spec`:
   ```python
   exe = EXE(
       ...
       icon='app_icon.ico',  # Добавьте эту строку
       ...
   )
   ```
4. Пересоберите: `python build_exe.py`

### Скрыть консоль (окно cmd)

В `app.spec` измените:
```python
console=False,  # Вместо True
```

Но учтите - без консоли вы не будете видеть сообщения об ошибках!

## 🐛 Решение проблем

### Ошибка "недостаточно памяти при сборке"

Попробуйте собрать с опцией `--onedir` вместо `--onefile`:
```bash
pyinstaller --onedir app.spec
```

Это создаст папку с файлами вместо одного exe.

### EXE не запускается

1. Проверьте консоль - там будут сообщения об ошибках
2. Убедитесь, что у вас установлены все зависимости из `requirements.txt`
3. Пересоберите exe: `python build_exe.py`

### Интернет-соединение

EXE загрузит данные с биржи MEXC через интернет. Убедитесь, что у вас есть соединение.

## 📤 Распространение

Файл `КалькуляторСетки.exe` из папки `release/` полностью готов к распространению:
- Не требует установки Python
- Не требует установки других программ
- Просто скопируйте и запустите

Можете отправить его другу, и он запустит его на своем Windows компьютере! 🎉
