📁 ФАЙЛЫ В ПАПКЕ exe_build/
================================

👥 ДЛЯ ПОЛЬЗОВАТЕЛЕЙ:

  📌 build.bat
     └─ Сборка EXE приложения
     └─ Как использовать: Дважды щелкните этот файл
     └─ Время: 3-5 минут на первый раз

  📌 install_dependencies.bat
     └─ Установка необходимых зависимостей Python
     └─ Как использовать: Запустите один раз перед первой сборкой
     └─ Дождитесь завершения

  📌 ИНСТРУКЦИЯ.txt
     └─ Подробная инструкция на русском языке
     └─ Шаг за шагом описано как использовать

  📁 release/
     └─ Папка с готовым EXE приложением
     └─ Откройте эту папку после сборки
     └─ Найдите КалькуляторСетки.exe и запустите его!


🔧 ДЛЯ РАЗРАБОТЧИКОВ:

  🐍 build_exe.py
     └─ Python скрипт управления сборкой
     └─ Вызывается автоматически из build.bat
     └─ Использование: python build_exe.py

  ⚙️  app.spec
     └─ Конфигурация PyInstaller
     └─ Описывает что включить в EXE
     └─ Включает пути к шаблонам и статическим файлам
     └─ Указывает зависимости (hiddenimports)

  📖 README.md
     └─ Техническая документация
     └─ Для понимания как работает сборка
     └─ Опции персонализации

  .gitignore
     └─ Настройка git игнорирования
     └─ Исключает временные файлы сборки


📊 ПАПКИ СБОРКИ (создаются автоматически):

  build/
     └─ Временные рабочие файлы PyInstaller
     └─ Удаляются при каждой сборке
     └─ Можно игнорировать

  dist/
     └─ Промежуточные файлы распределения
     └─ Тоже удаляются при сборке
     └─ Можно игнорировать


🎯 ТРОЙКА САМЫХ ВАЖНЫХ ФАЙЛОВ:

  1️⃣  build.bat           ← Запустите это первым!
  2️⃣  install_dependencies.bat  ← Потом это (один раз)
  3️⃣  release/КалькуляторСетки.exe  ← Это ваше готовое приложение!


⚡ БЫСТРЫЙ СТАРТ:

  Шаг 1: Дважды щелкните install_dependencies.bat
  Шаг 2: Дождитесь завершения
  Шаг 3: Дважды щелкните build.bat
  Шаг 4: Дождитесь завершения
  Шаг 5: Откройте папку release/
  Шаг 6: Дважды щелкните КалькуляторСетки.exe
  Шаг 7: Готово! Приложение запущено! 🚀


📝 ЗАМЕЧАНИЯ:

  ✓ Все исходные файлы проекта остались неизменными
  ✓ Они находятся в родительской папке
  ✓ Эта папка содержит ТОЛЬКО инструменты для сборки EXE
  ✓ После сборки EXE можно распространять без Python


💬 НУЖНА ПОМОЩЬ?

  - Прочитайте ИНСТРУКЦИЯ.txt
  - Посмотрите README.md для технических деталей
  - Проверьте что Python установлен: откройте cmd и введите "python --version"
  - В exe_build/build.bat есть проверки на ошибки


✅ ЦЕЛЬ:

  У вас будет один файл КалькуляторСетки.exe (~50-80 MB)
  Который работает на любом Windows компьютере БЕЗ установки Python!
