# 🚀 ЗАПУСК И СБОРКА EXE ПРИЛОЖЕНИЯ

## ⚡ Самый быстрый способ (для Windows)

### Шаг 1: Установка (только один раз)
1. Откройте папку `exe_build/`
2. Дважды щелкните `install_dependencies.bat`
3. Дождитесь завершения установки (появится сообщение)

### Шаг 2: Сборка EXE
1. Откройте папку `exe_build/`
2. Дважды щелкните `build.bat`
3. Дождитесь завершения (займет 3-5 минут)
4. Готовый `КалькуляторСетки.exe` будет в папке `release/`

### Шаг 3: Запуск
- Найдите `КалькуляторСетки.exe` в папке `release/`
- Дважды щелкните - и приложение запустится!
- Автоматически откроется браузер с приложением

---

## 💻 Для профессионалов (через командную строку)

```bash
# Перейдите в папку проекта
cd C:\Users\Home\Desktop\ДЗ\ЕРИПТОТРЕКЕР

# Установите зависимости (один раз)
pip install PyInstaller
pip install -r requirements.txt

# Перейдите в папку exe_build
cd exe_build

# Соберите EXE
python build_exe.py
```

---

## 📋 Что происходит?

1. **PyInstaller** анализирует ваш код Python
2. Собирает все зависимости (Flask, requests и т.д.)
3. Включает Python runtime (интерпретатор) внутрь
4. Создает однофайловый EXE
5. Этот EXE можно запустить на любом Windows компьютере БЕЗ установки Python!

## ⚠️ Важно!

- **Первая сборка**: Займет 3-5 минут (нормально!)
- **Последующие сборки**: Будут быстрее (~1-2 минуты)
- **Файл большой**: EXE весит 50-80 MB (это нормально - внутри Python!)
- **Требуется интернет**: При запуске загружает данные с биржи MEXC

## 🛠️ Изменить иконку приложения

1. Подготовьте иконку (файл .ico, 256x256 пиксела)
2. Сохраните её как `app_icon.ico` в папке `exe_build/`
3. Отредактируйте `app.spec`:
   ```
   Найдите строку:   exe = EXE(
   Добавьте внутрь:  icon='app_icon.ico',
   ```
4. Пересоберите: `python build_exe.py`

## 🐛 Если что-то не работает

### Ошибка: "Python не найден"
- Установите Python с https://www.python.org/
- При установке отметьте ✓ "Add Python to PATH"
- Перезагрузите компьютер

### Ошибка: "Недостаточно памяти"
- Закройте другие программы
- Попробуйте собрать еще раз

### EXE не запускается
- Откройте командную строку и запустите так: `КалькуляторСетки.exe`
- Будут видны ошибки в консоли
