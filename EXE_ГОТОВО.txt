## 🚀 БЫСТРЫЙ СТАРТ

### Для обычных пользователей (самый простой способ)

1. **Откройте папку `exe_build/`**

2. **Первый запуск (один раз):**
   - Дважды щелкните `install_dependencies.bat`
   - Ждите (установятся Python зависимости)

3. **Сборка EXE:**
   - Дважды щелкните `build.bat`
   - Ждите 3-5 минут (первая сборка дольше)

4. **Запуск:**
   - Откройте папку `release/`
   - Найдите `КалькуляторСетки.exe`
   - Дважды щелкните - и вперед! 🚀

### Для разработчиков (через терминал)

```powershell
# Перейдите в папку проекта
cd C:\Users\Home\Desktop\ДЗ\ЕРИПТОТРЕКЕР\exe_build

# Установите PyInstaller
pip install PyInstaller

# Соберите EXE
python build_exe.py
```

## 📝 Что такое эти файлы?

### `build.bat`
Батник для сборки. Запустите его и спокойно ждите - сам всё сделает.

### `install_dependencies.bat`
Батник для установки необходимых Python пакетов. Запустите один раз.

### `build_exe.py`
Python скрипт, который управляет процессом сборки. Используется батником.

### `app.spec`
Конфигурационный файл PyInstaller. Указывает, что включить в EXE, какие файлы скопировать и т.д.

### `ИНСТРУКЦИЯ.txt`
Подробная инструкция на русском для пользователей.

### `README.md`
Техническая документация для разработчиков.

## 💡 Как это работает?

1. **PyInstaller** - это инструмент, который упаковывает Python код
2. Он включает внутрь EXE весь Python runtime (интерпретатор)
3. Добавляет все необходимые библиотеки (Flask, requests и т.д.)
4. Результат - один исполняемый файл, который работает без Python на компьютере

**Аналогия:** Если обычно для запуска нужно "иметь кухню" (Python), то EXE - это "готовое блюдо", которое можно сразу съесть! 🍕

## ❓ Частые вопросы

### Q: Почему EXE такой большой?
A: Потому что внутри весь Python (интерпретатор). Это нормально - работает быстро.

### Q: Можно ли открыть EXE и посмотреть код?
A: Технически можно декомпилировать, но очень сложно. Это достаточно защищено.

### Q: Сколько времени занимает сборка?
A: Первая - 3-5 минут. Последующие - 1-2 минуты.

### Q: Нужен интернет для работы приложения?
A: Да, для загрузки данных с биржи MEXC нужно интернет-соединение.
